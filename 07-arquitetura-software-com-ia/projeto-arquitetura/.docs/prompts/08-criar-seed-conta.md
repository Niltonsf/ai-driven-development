Criar seed de banco de dados para a tabela de contas. Exemplos de contas:

- Conta Conjunta BB
- Conta Poupança Caixa
- C6 Salário
- Conta Investimento XP

Criar exemplos realista de conta dentro do arquivo apps/backend/prisma/seed/data/contas.json

E alterar o arquivo apps/backend/prisma/seed/main.ts e executar o preenchimento do banco de dados com os dados gerados.

Evite duplicações, ou seja, não deve incluir as mesmas contas de forma duplicada.
