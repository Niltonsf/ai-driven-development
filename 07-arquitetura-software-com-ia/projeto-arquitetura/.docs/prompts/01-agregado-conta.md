/module-aggregate  Criar um agregado dentro do módulo de contas @modules/contas com o nome conta com os seguintes atributos:

- id (herdar de entidade)
- nome
- descrição (opcional)
- agencia (opcional)
- número da conta (opcional)
- nome da instituição (opcional)
- status de ativa (padrão = true)
- cor (opcional)
- icone (opcional) (string)
