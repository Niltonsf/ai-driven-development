Eu quero que você implemente dentro do authController uma chamada para o caso de uso de registrar usuário. Esse caso de uso demanda duas implementações: uma implementação de um repositório e uma implementação de uma criptografia de senha, que já estão as implementações contidas diretamente aqui na pasta do módulo de autenticação. Além de chamar o caso de uso de uma forma simples, passar as implementações na construção do caso de uso e fazer essa funcionalidade funcionar, você precisa criar um arquivo com a extensão .HTTP para a gente testar as funcionalidades do módulo de autenticação. E para isso você vai usar o padrão de testes e definição de chamadas de API do plugin do Visual Studio Code chamado REST Client. Então criar ali um auth.integration.HTTP para a gente fazer esses testes de integração com a API que vai ser criada dentro do auth.controller.ts.
