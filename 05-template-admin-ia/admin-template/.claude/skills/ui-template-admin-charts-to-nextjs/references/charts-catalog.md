# Charts catalog

Taxonomy of chart primitives generated by this skill. The minimum set is always generated; additional types only when present in the template.

## Minimum set (always generated)

| Type | File | Variants (prop) | Notes |
|---|---|---|---|
| Bar chart | `bar-chart.component.tsx` | `simple` \| `stacked` \| `grouped` \| `horizontal` | Vertical by default. Replicate top-corner radius from template. |
| Line chart | `line-chart.component.tsx` | `simple` \| `multi-series` | Stroke width, smooth/straight/stepped, marker behavior from template. |
| Area chart | `area-chart.component.tsx` | `simple` \| `stacked` | Gradient fill (extract exact stops). |
| Pie chart | `pie-chart.component.tsx` | — | Start angle, slice gap from template. |
| Donut chart | `donut-chart.component.tsx` | `with-center-label` \| `plain` | Inner radius ratio from template. |
| Sparkline | `sparkline.component.tsx` | `line` \| `area` \| `bar` | Minimal: no axes, no grid, no legend, ~40–60px height. |

## Support wrappers (always generated)

| Component | File | Purpose |
|---|---|---|
| `ChartContainer` | `chart-container.component.tsx` | Card wrapper with header (title, subtitle, actions), body (chart slot), footer. Consumes `Card` from `ui/` if present. |
| `ChartLoading` | `chart-loading.component.tsx` | Skeleton with chart-shaped placeholder, animated `pulse`. |
| `ChartEmptyState` | `chart-empty-state.component.tsx` | Icon + message; optional `action` slot. |
| `ChartTooltip` | `chart-tooltip.component.tsx` | Custom React tooltip (only when library supports React tooltip override). |
| `ChartLegend` | `chart-legend.component.tsx` | Custom React legend (only when library supports custom legend). |

## Additional set (only if template has them)

| Type | File | Trigger condition |
|---|---|---|
| Radial bar | `radial-bar-chart.component.tsx` | Template has progress-circle / radial-bar instances |
| Radar | `radar-chart.component.tsx` | Template has radar/spider charts |
| Gauge | `gauge-chart.component.tsx` | Template has gauges/meters |
| Heatmap | `heatmap-chart.component.tsx` | Template has heatmaps (calendar heatmap, density grids) |
| Scatter | `scatter-chart.component.tsx` | Template has scatter / bubble charts |
| Mixed | `mixed-chart.component.tsx` | Template combines bar+line in same chart |
| Funnel | `funnel-chart.component.tsx` | Template has funnel/pipeline charts |
| Treemap | `treemap-chart.component.tsx` | Template has treemap |

## Out of scope

These are explicitly NOT generated, even if the template has them:

- Geographic maps / choropleths (separate skill)
- 3D charts
- Candlestick / OHLC / financial charts (separate skill, unless template explicitly has them)
- Network/graph diagrams
- Sankey diagrams (unless template explicitly demonstrates a clear, isolated example)
- Word clouds

## Naming convention

`<chart-type>.component.tsx` — kebab-case filename, PascalCase export. Match the convention already established by the primitives skill (read `src/shared/components/ui/index.ts` to confirm).
