# CA rule: source of truth

One book, one PDF, nothing else.

## The source

`clean-architecture-a-craftsmans-guide-to-software-structure-and-design.pdf`
Robert C. Martin, *Clean Architecture: A Craftsman's Guide to Software
Structure and Design*, Pearson, 2018. 364 PDF pages. Never modified.

Chapter to PDF page mapping: `../references/page-index.md`, generated by
`python3 tools/ca_pdf.py index`.

## What counts as a rule

A statement may enter a `ca-*` skill, rule, card or command only if it can be
pointed at a PDF page inside chapters 1-34 (PDF pages 25-240).

The appendix (pp.242-274) and the book index (pp.275-364) are not normative
material for these artifacts.

## What does not count

Not in this PDF, therefore never in a `ca-*` artifact:

| Excluded | Handling |
|---|---|
| *Clean Code*, *The Clean Coder*, *Agile Software Development* | `OUT_OF_SCOPE` |
| DDD vocabulary: aggregate, value object, bounded context, domain event, ubiquitous language | `OUT_OF_SCOPE` |
| Hexagonal beyond Simon Brown's paragraphs in ch.34 | `OUT_OF_SCOPE` |
| Onion, vertical slice, CQRS, event sourcing as an architecture | `OUT_OF_SCOPE` |
| Conventions of this repository's other folders (NestJS layout, Prisma, `Result`) | `OUT_OF_SCOPE` |
| A folder tree derived from ch.21 | `OUT_OF_SCOPE` |
| A fixed count of four layers derived from the ch.22 diagram | `OUT_OF_SCOPE` |
| anything else absent from pp.25-240 | HALT (`OUT_OF_SCOPE`) |

## Looking a claim up

```
python3 tools/ca_pdf.py search "dependency rule"   # which pages carry the term
python3 tools/ca_pdf.py pages 161-166              # read those pages
python3 tools/ca_pdf.py verify                     # prove the citation resolves
```

A claim that survives `verify` is a rule. A claim that does not is a halt.
